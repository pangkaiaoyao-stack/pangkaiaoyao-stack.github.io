DEEP LEARNING · MOBILE APPLICATION

AI-Based Emotion Detection
Mobile Application

A computer-vision based mobile application designed to detect facial emotions and connect the prediction with a music recommendation experience.

The system works through a Flutter mobile interface and a Flask backend. MediaPipe is used for face localization, while deep learning models process facial information for seven emotion classes.

Angry Disgust Fear Happy Sad Surprise Neutral
RAF-DB EfficientNet MLP MediaPipe Flask Flutter
01

Problem

Human emotions are naturally expressed through facial features. The project explores how computer vision and deep learning can interpret these expressions and turn them into useful application-level output.

02

Approach

Multiple deep learning architectures were trained and compared. EfficientNet was combined with an MLP classifier to improve the final emotion classification pipeline.

03

Application

A Flutter mobile application communicates with the Flask backend through HTTP requests. The backend processes the image and returns the predicted emotion and confidence information to the application.

05 · PROJECT JOURNEY

How the idea
comes together.

01

Dataset

Working with RAF-DB and seven emotion categories to build the foundation for facial emotion classification.

02

Face Localization

MediaPipe helps locate facial information before the image is passed through the emotion recognition pipeline.

03

Feature Learning

Different CNN-based architectures are explored to understand which approach performs better for the task.

04

Fusion

EfficientNet features are combined with an MLP classifier to create the final model pipeline.

05

API

Flask provides the backend layer that receives image data and returns the model's prediction.

06

Mobile App

Flutter connects the backend prediction to an interactive mobile application interface.
