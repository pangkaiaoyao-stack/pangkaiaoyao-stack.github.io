Pangkai H Konyak Portfolio

Files:
- index.html
- style.css
- script.js
- assets/

Quick start:
1. Keep all three files in the same folder.
2. Open index.html in a browser to preview.
3. To add your profile photo, put it in assets/profile.jpg and replace the PK placeholder in index.html with:
   <img src="assets/profile.jpg" alt="Pangkai H Konyak">
